# Jogo: Escape from Gotham

Jogo simples de navegador em que você controla o Batman e tenta desviar do Bane para salvar Gotham. O projeto foi feito com HTML, CSS e JavaScript, sem dependências externas.

## Como jogar

Abra `index.html` em um navegador. Pressione **B** ou toque na área do jogo para iniciar ou reiniciar. Pule com **barra de espaço**, **seta para cima** ou toque na tela. Se Batman colidir com Bane, o jogo termina.

## Arquivos do projeto

- `index.html`: estrutura da página, personagens, mensagens e referências ao CSS e JavaScript.
- `css/style.css`: aparência do jogo, cenário, animações e layout responsivo para telas menores.
- `js/script.js`: controles de teclado e toque, início e reinício da partida, pulo e detecção de colisão.
- `assets/img/cenario.webp`: imagem de fundo do jogo.
- `assets/img/Batman.gif`: personagem controlado pelo jogador.
- `assets/img/Bane.png`: obstáculo que deve ser evitado.
- `assets/img/game-over.png`: imagem exibida ao fim da partida.
